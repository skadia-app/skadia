## services/api/internal/strava/importer_media.go — Fix video thumb bug + set IsVideo

**Suche nach:** importer_media / TODO migration-000138
**Delta:**
- Removed TODO comment about IsVideo — now actually sets `IsVideo: isVideo` in the ActivityPhoto struct
- Sets `DurationS`, `VideoWidth`, `VideoHeight` from `imageutil.ProbeVideo()` when `isVideo=true`
- Added extension-based video detection guard: if `contentType` claims image/* but file extension is a video container (`.mp4`, `.m4v`, `.mov`, `.avi`, `.mkv`, `.webm`), force `isVideo=true` and re-derive correct content type — this is the root-cause fix for `s3_key_thumb` pointing to `.mp4`
- Added helper functions `isVideoExtension(ext)` and `videoContentTypeFromExt(ext)` at bottom of file
