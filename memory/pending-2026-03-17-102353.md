## services/api/internal/fitimport/streams.go + tcximport/parser.go — fix partial distance stream bug

**Suche nach:** deriveGPSMetrics
**Delta:**
- Bug: `deriveGPSMetrics` (FIT) und `deriveTCXGPSMetrics` (TCX) prüften "hat irgendein Punkt DistanceM != nil" → sprangen den ganzen Derivations-Block über.
- Für Pre-2015 Garmin-Geräte, die Distance nur für die erste GPS-Lock-Periode (~1 km) speichern, führte das dazu dass der `distance_m`-Stream nach ~1 km aufhörte. Frontend forward-filled Null-Werte → X-Achse kollabiert auf 0–1 km.
- Fix: `hasDist = true` nur wenn letzter Punkt (oder innerhalb letzter 1% der Punkte) einen nicht-nil DistanceM-Wert hat → partial streams werden via GPS-Haversine neu abgeleitet.
- Betroffene Dateien: `services/api/internal/fitimport/streams.go`, `services/api/internal/tcximport/parser.go`
- Aktivitäten müssen neu importiert werden (Re-Import aus Original-FIT/TCX-Datei).
