## frontend/src/pages/MapPage.tsx — Terra Incognita + Overlay Bug Fixes

**Suche nach:** isStyleLoaded, Terra Incognita, Kartenebenen

**Delta:**
- Bug 1 fix: In `useEffect` für Overlay-Layer (Effect 1) und Terra Incognita Layers (Effect 2): `!map.isStyleLoaded()` ersetzt durch `styleVersion === 0` als Guard. `isStyleLoaded()` gibt false zurück während Tiles dekodiert werden → TI-Nebel wurde nie gerendert wenn Daten während Tile-Processing ankamen. `styleVersion === 0` prüft nur ob `style.load` überhaupt je gefeuert hat.
- Bug 2 fix: Gleicher `isStyleLoaded()` Fix für Effect 1 (Track/Heatmap Overlay). Wurde zwar hauptsächlich durch onClick-Handler gebridged, aber Race Condition beseitigt.
- Strukturfix: `{/* Kartenebenen */}` Div (Gipfel/Gewässer/Wälder/Einkehr/Segmente-Toggles) war als normaler in-flow Block direkt im Map-Container — korrekt unzugänglich aber strukturell falsch. Nach `MapFilters` verschoben.
- `MapOverlayState` interface exportiert
- MapFilters.tsx erhält neue optionale Props: `overlayState`, `onOverlayChange`, `segmentFilters`, `onSegmentFiltersChange`, `segmentColors`, `onSegmentColorsChange`
- MapFilters zeigt Aktivitäts-Filter-Sektionen nur wenn `viewMode !== 'terra_incognita'` (vorher komplett ausgeblendet in TI-Mode, jetzt Panel immer sichtbar)
- MapPage: `{viewMode !== 'terra_incognita' && <MapFilters .../>}` → `<MapFilters .../>` (immer sichtbar), mit Overlay-State Props übergeben
