# Skadia Wiki

Dieses Verzeichnis enthalt die ausfuhrliche technische Dokumentation einzelner Skadia-Features. Jedes Dokument beschreibt ein Feature vollstandig (Algorithmus, Datenmodell, API, Frontend-Integration) und ist so aufgebaut, dass es in eine zusammenhangende Softwaredokumentation integriert werden kann.

## Inhaltsverzeichnis

| Dokument | Feature | Betroffene Schichten |
|---|---|---|
| [sonnenstandserkennung.md](sonnenstandserkennung.md) | Track-basierte Sunrise/Sunset-Berechnung | Backend, Datenbank, Frontend |

## Konventionen

- **Ein Dokument pro Feature** — jedes Dokument ist eigenstandig lesbar
- **Einheitliche Struktur:** Uebersicht, Algorithmus, Datenmodell, API, Frontend, Dateien, Verifikation
- **Querverweise** zu den Hauptdokumenten in `docs/` wo noetig
- **Kein Duplikat** — Details stehen hier, Zusammenfassungen in `docs/`
